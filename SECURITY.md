# Security policy

## Reporting a vulnerability

Please use GitHub [**Security advisories**](https://github.com/jasper0507/idea-harness/security/advisories/new) to report anything that could realistically harm users (for example: workflow injection, secret leakage, or malicious scripts).

This repository is **skill-first** (Markdown plus small shell scripts). Treat unexpected script behavior or altered verification logic as security-relevant if it could affect downstream automation.

## Supported versions

Security fixes are applied on the default branch (`main`). Tag-based releases follow SemVer; patch fixes may appear as a new patch tag.

## Disclosure

Please allow maintainers a reasonable window to ship a fix before public disclosure. If you believe an issue is already being exploited, say so explicitly in the advisory.
