# 词汇表

## 内部术语（不得暴露给用户）

| 术语 | 定义 |
|------|------|
| **门槛** (Gate) | 七个必需澄清检查点之一 |
| **精确度缺口** (Precision Gap) | 门槛已有回答但不够精确 |
| **隐藏默认值** (Hidden Default) | 用户未确认但其回答暗含的假设 |
| **危险假设** (Dangerous Assumption) | 默认阻止列表中的内容 |
| **范围边界** (Scope Boundary) | V1 不做的事项 + 原因 |
| **阻断条件** (Blocking Condition) | 必须解除才能继续的冲突或未确认假设 |
| **行为契约** (Behavior Contract) | 执行 Prompt 中描述"做什么"而非"用什么 UI" |

## 用户用语规范

- 镜像用户的用词。用户说"记一下"就用"记"，不改成"录入"。
- 不引入用户没用过的专业词汇：MVP、PRD、spec、use case、user story、stakeholder。
- 模糊词不直接替换，追问它在用户场景里具体指什么。

### 常见歧义词

| 词 | 可能含义 | 追问方向 |
|----|---------|---------|
| "保存" | 浏览器本地 / 文件 / 云端 / 数据库 | "下次打开还在吗？换设备呢？" |
| "通知" | 浏览器推送 / 邮件 / 页面内提示 | "在哪里看到这个通知？" |
| "管理" | 增删改查 / 统计 / 审批 / 归档 | "管理的时候你具体做什么动作？" |
| "记录" | 文字 / 数字 / 图片 / 时间线 | "记下来的一条长什么样？" |
| "分享" | 发链接 / 截图 / 协作编辑 | "对方看到后能做什么？" |
| "同步" | 多设备 / 多人 / 实时 / 备份 | "换设备也要看到？还是怕丢？" |
| "简单" | 功能少 / 步骤少 / 界面干净 | "简单是指用起来步骤少，还是功能少？" |

### 用户可见输出中避免的词汇

- 技术术语：API、CRUD、localStorage、数据库、前端、后端、部署、SDK
- 流程术语：MVP、PRD、需求规格、验收测试、利益相关者、用例
- 内部术语：门槛、精确度缺口、阻断条件、状态机、Harness Gate、行为契约
