# Idea Harness

面向非程序员的小应用想法澄清器。

Idea Harness 帮普通人把一句模糊的“小网站、小工具、小应用”想法，澄清到 AI 不需要脑补也能继续执行的程度。它不是 PRD 生成器、Prompt 优化器，也不是技术方案生成器。

差异化很窄：**只服务非程序员的早期想法澄清**。

## 适合什么

- 你只有一句模糊想法，例如“我想做一个学习管理网站”。
- 你不知道怎么写需求，但希望 AI 不要乱加功能。
- 你想先做一个很小的第一版，而不是一上来变成复杂系统。
- 你需要先说清楚目标、使用者、流程、边界和验收标准。

## 不做什么

- 不选择技术栈。
- 不设计数据库、后端、部署或安全架构。
- 不生成代码。
- 不写厚重 PRD。
- 不把普通人的一句想法包装成完整产品方案。

## 使用方式

把 skill 目录交给支持 `SKILL.md` 的 agent 使用：

```text
skills/idea-harness/SKILL.md
```

示例：

```text
使用 idea-harness 先澄清我的小应用想法。
我想做一个学习管理网站。
```

它会先判断现在能不能继续。如果信息还不够，它只问一个最关键的问题：

```markdown
## 当前结论
Status: Need More Info
Reason: “学习管理网站”还太宽，最容易跑偏的是先管理哪类学习内容。

## 已确认
- 你想做一个学习管理网站。

## 不能先假设
- 不能先假设它是任务管理器、课程表、笔记库、登录产品、数据库产品或图表看板。

## 下一步
你最想先管理哪一类学习内容？
A. 每天要做的学习任务
B. 作业和截止日期
C. 学习笔记或资料
D. 学习时间和打卡
```

只有当目标、使用者、核心流程、第一版必须有、第一版不做、数据保存行为、验收标准和必要业务边界都说清楚后，它才会进入 `Ready`，并输出 `执行 Prompt`。
